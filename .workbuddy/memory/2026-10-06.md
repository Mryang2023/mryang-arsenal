### 断言逼出来的四个引擎缺陷（读代码看不出来，全是 fixture 跑出来的）
1. **预筛比正式匹配严格**：预筛用整词 indexOf，`Order` 的近义变体 `Ord` 所在文件被整份漏掉 → 预筛改词根前 3 字符
2. **词干还原错**：`rules` 走 es 得 `rul`（只去 s 不去 es）；`ruled` 单看单词分不出 `rule+d`/`rul+ed` → ed 去后两个候选都试，命中集合的算
3. **近义分支漏 key**：variant 分支没返回 `key` → 所有近义变体挤进 Map 的同一格（**症状是变体数恒为 2 且不报错**）；断言里补「两个不同近义变体各占一格」守这条
4. **副本注入 $& 陷阱**：`escapeLiteral` 源码含 `$&`，字符串形式的 `String.replace` 把它当替换模式 → import 行被插进函数体中间；改函数形式替换

教训（第 5 次了）：**写完判据第一件事是跑**。这四个 bug 静态读代码一个都看不出来。
