### 挖到的真 Bug（B0，未修）
`/cases` **切场景会白屏**：`case-types.ts:110` 的 `benchmark` 是**必选字段**（无 `?`），
但 6 个场景里 **4 个没这个字段**（high-throughput-io / hotspot-cache / async-pipeline / wide-table-search，
只有 huge-rowcount-rdb 与 genomic-sequence-store 有）。`CaseLab.tsx:628` 无守卫读 `kase.benchmark.title`。
默认场景 `cases[0]`=`huge-rowcount-rdb` **恰好有** ⇒ 静态预渲染不崩、shoot 45 张全绿，
**用户点到第 3 个场景才炸**。根因是**类型声明对数据撒谎**，690 条断言没抓住。
补断言方向：「类型必选字段 ↔ 事实源实际字段存在性」一致性。

### 做图必知的四个硬事实（写错就返工）
1. **`flow[].layer`（调用层：client/web/service/repo/sql/concurrency）与 `files[].layer`
   （构件层：web/dto-in/dto-out/service/repo/domain/exception/common/sql/config/integration/structure/test）
   是两套词表**，别映射成一套。
2. **`flow` 不是单向链**：crud-basic 末步回到 `web`（GlobalExceptionHandler 旁路）、
   async-transaction 末步回到 `client`（异步闭环）⇒ 链路图数据结构必须是「节点+有向边」，支持回程边。
3. **`slices[].when` 可以是 `{}`** = 无条件命中（hotspot-cache 的「可观测与降级兜底」）。
   命中矩阵必须**四态**：条件命中 / 无条件命中 / 该切片不约束此参数 / 未命中。
4. 匹配不到代码文件的链路节点标 `fgFaint` 且**不可点**；架构节点无理由时显示「未标注原因」，不编造。

### 裁决
- **不引图表库**，全手写 SVG（现有 arch-diagram/arch-motion/arch-layered 覆盖 ~70%）。
- **不动事实源 JSON**（关联在 `case-synth.ts` 合成期确定）。真加字段是 **3 处**不是 4 处

- **不新增路由**：新增顶层路由会让 `shoot.mjs` 的 `EXPECTED{fixedPages:10,urls:15,shots:45}` mismatch，
  二级路由「未归类 → 永不被断言」。全部在现有路由内做页签/抽屉。
- 拆 `CaseLab.tsx` 时**必须保留 `CaseLab` 入口名与 `'use client'`**（`verify:cases` 有源码文本断言）。
