4. **nacos 片段缺 server-addr / spring.config.import**：nacos-config 在 classpath 时启动即因 import 检查失败退出。

连带真 bug：`stack_data.py` mybatisplus 片段 `mapper-locations` 顶格（在 `mybatis-plus:` 块外，键被静默丢弃）；`stack_mw.py` registry/nacos 片段带 `spring.application.name: arsenal-demo` + `profiles.active: dev`，多文档后文档覆盖前文档，会把用户项目名改掉。
