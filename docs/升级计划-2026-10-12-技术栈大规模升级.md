## 二、为什么是这个方向（取舍记录）

1. **Next 16 而不是 15**：15 已过维持期，16.4 是当下 latest 稳定线，Turbopack 成为默认构建器，
   与 Tailwind 4 是官方搭档。仓库用 `output: 'export'` 静态导出 + 自定义 `next-run.mjs` 包装，
   这两处是重点回归对象。
2. **Tailwind 4**：设计上就是为 Turbopack / v4 引擎而生。配色单一来源（`stack/palette.ts` 的
   TONE → tailwind.config.ts）在 v4 的 CSS-first `@theme` 下断了 —— 处理方案二选一：
   a) **首选**：把 TONE 色值纳入 sync 代码生成（palette.ts → 生成 CSS token 文件 → globals.css 引入），
      沿仓库「一份数据、防漂移闸门」的既有哲学；
   b) 兜底：v4 官方 `@config` 指令继续吃旧 tailwind.config.ts（半迁移，可交付但不优雅）。
   另需全仓扫 v4 改名的工具类（shadow-sm→shadow-xs、outline-none→outline-hidden、bg-opacity-* 移除等）。
3. **TS 停在 5.9 不上 7**：TS 7.0.2 是 Go 原生编译器首稳定版，`tsx`（esbuild）与 Next 16 的类型生态
   都还锚在 5 线；军火库十层 verify 的价值远大于 tsc 提速，不为版本号冒险。
4. **Spring Boot 4.1.1 而不是 3.5.x**：3.5 是过渡版；4.1.1 是稳定线最新。Jackson 2 → 3 是唯一
   真迁移点（10+ 文件 import com.fasterxml.jackson.databind → tools.jackson.databind；
   注解包 com.fasterxml.jackson.annotation 在 Jackson 3 里保持不变，受检异常 JsonProcessingException
   → 非受检 JacksonException）。
5. **顺手收编**：application.yml 里「主服务仍跑 JDK 17，不改」的注释随升级改成事实；
   开 `spring.threads.virtual.enabled=true`（仓库自己就在教虚拟线程）；给 arsenal-server
   补 Maven Wrapper，构建不再依赖本机 PATH。

### Tailwind 4 迁移路线

走了**首选方案（代码生成）**：新增 `scripts/gen-theme-tokens.ts`，由
`src/app/stack/palette.ts` 的 TONE 生成 `src/generated/theme-tokens.css`（@theme 块），
挂进 sync 链头部，带 `--check` 防漂移模式；tailwind.config.ts 删除。
工具类改名全仓清扫：`outline-none→outline-hidden`（20 处）。
v3 边框默认色兼容垫片（#e5e7eb）进了 globals.css —— 200+ 处裸 `border` 视觉不变。
`mono` 从 @layer components 改注册为 `@utility`（v4 的 @apply 只认 utility）。

### 计划外发现并修复的问题

1. **Next 16 动态路由空壳页（P0）**：`rules/[id]`、`cases/[caseId]`、`blueprints/[topic]`
   两层共 4 组页面同步解构 `params` —— Next 15+ 起 params 是 Promise，静态导出下
   渲染出整页空壳（`<h1>` 数 0、正文底 0）。全部改 async + await。
2. **视觉断言在 Edge 92 下全是假象（P0）**：本机 Edge 是 92（2021），Tailwind 4 产物
   整个装在 CSS `@layer` 里（Chromium 99+ 才支持），Edge 92 把 utilities 整层丢弃 ——
   实测 `.overflow-auto` 在 CSS 文件里存在、加载后 CSSOM 里没有，A1「溢出」、A5「对比度」
   失败全是无样式的假布局。`visual/browser.mjs` 新增 ⓪ 号路径：Playwright 自带 chromium
   （已 `playwright install chromium`，现代内核）优先于 Edge。
3. **A8 断言测量法缺陷（存量，非升级回归）**：`r.bottom + (docH - vh)` 把「全程钉在
   视口顶的 top-0 包裹层」当成随页面滚走。用 git worktree 建了升级前基线（46ce7c5）
   实跑同一断言：旧栈同样 52 页 58 失败 —— 存量问题。按断言注释自述的语义改成
   「真滚到底再量 rect」，判据不动；修复后视觉矩阵 **99 张 / 0 失败 / exit 0**（首次全绿）。
4. **Jackson 3 两处适配**：`fields()→properties()`、`fieldNames()→propertyNames()`
   （5 处）；`JsonProcessingException→JacksonException`（非受检，2 处 catch + 1 处
   `catch (IOException)` 死代码改为 `JacksonException`）。
5. **脚本 JDK 口径**：`_cp.sh` 扫描 17→21、Jackson 依赖坐标换 `tools/jackson/core/*`
   （注解包留 com.fasterxml，3.x 配 2.21 注解线）、去掉 Spring 7 已删除的 spring-jcl；
   `parity-probe.sh` 改用 19+ 标准的 `stdout.encoding`。
