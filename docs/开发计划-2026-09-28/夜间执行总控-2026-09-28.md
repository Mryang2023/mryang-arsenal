- 角色 `GET /api/roles`（**分页**，前端下拉用 size=500 拉全量）、POST/PUT/DELETE、`GET/PUT /api/roles/{id}/permissions`（提交只传 type=leaf 的 id）；权限树 `GET /api/permissions/tree` → `[{id,label,permission,type:'group'|'leaf',children}]`。
- 菜单 `GET /api/menus/tree`、POST/PUT/DELETE `/api/menus`。token 放 `Authorization: Bearer <token>`，401=未登录/过期。

TS 接口（放 `arsenal-web/src/lib/scaffold/contracts.ts`，第三棒建，第四棒照用；字段名可按 module.json 实际微调但要在 contracts 注释里说明）：

```ts
/** 用户在「环境与连接」步骤填的值；key 用 envForms 声明的字段 key（如 db.host） */
export type EnvValues = Record<string, string>;
export interface EnvInput { demoMode: boolean; values: EnvValues; }
export interface ModulePick { id: string; }   // 勾选的模块 id（mod-user/mod-role/mod-menu）
export interface ExportFile { path: string; content: string; group: string; from?: string; }
export interface ExportArtifact { name: string; files: ExportFile[]; bytes: number; }
export interface ExportArtifacts {
  backend: ExportArtifact;      // {name}-backend.zip 内容
  frontend?: ExportArtifact;    // fe.base=none 时缺省
  all: ExportArtifact;          // {name}-all.zip：backend/ + frontend/ + compose + 脚本 + 根 README
}
```

打包复用 `src/lib/zip.ts downloadZip()`（store 模式纯文本，够用）。三包组装放 `src/lib/scaffold/artifacts.ts buildExportArtifacts(picks, meta, env, moduleIds)`。
