## 6. 已知坑（今晚大概率还会遇到）

| 坑 | 规避 |
|---|---|
| 后端 3011 半夜会死 | 每棒开工先探活，DEAD 就起 |
| `npm run <script>` 在 Git Bash exit 1 | 直接跑脚本本体或 `node npm-cli.js run` |
| 视觉层断言的是 `out/` | 先 build 再 verify，否则全跳过看着也"绿" |
| `git checkout --` 抹掉未提交改动 | **用 `cp` 备份还原** |
| 并行改同一文件静默丢改 | 一棒一文件；同一文件多处改动必须串行 |
| 目录级 `git add` 夹带 `_*` | 逐文件 add + `grep '/_'` 复核 |
| 注入打空、检查仍绿 | 注入后先 grep 确认打中再跑检查 |
